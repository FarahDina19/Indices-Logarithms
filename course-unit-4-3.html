Master converting between exponential and logarithmic equations

  • Apply conversions to solve equations

The Fundamental Relationship

Exponential and logarithmic forms are two ways of expressing the same mathematical relationship:

Core Principle

Exponential Form:
ax = b
⟺
Logarithmic Form:
loga(b) = x

"To what power must we raise a to get b?" Answer: x

Understanding the Components

Example: Identifying Parts

Exponential Form: 2⁵ = 32

  • Base (a): 2 - the number being multiplied
  • Exponent (x): 5 - how many times the base is used
  • Result (b): 32 - the answer

Logarithmic Form: log₂(32) = 5

Common Logarithm Bases

Base 10 (Common Logarithm)

Exponential:
10² = 100
⟺
Logarithmic:
log(100) = 2

Base e (Natural Logarithm)

Exponential:
e¹ ≈ 2.718
⟺
Logarithmic:
ln(e) = 1

General Base a

Exponential:
ax = b
⟺
Logarithmic:
loga(b) = x

Conversion Examples

Example 1: Exponential to Logarithmic

Convert: 2⁵ = 32

Identify the parts:

  • Base (a) = 2
  • Exponent (x) = 5
  • Result (b) = 32

Logarithmic form: log₂(32) = 5

Example 2: Logarithmic to Exponential

Convert: log₃(81) = 4

Identify the parts:

  • Base (a) = 3
  • Logarithm (x) = 4
  • Argument (b) = 81

Exponential form: 3⁴ = 81

Example 3: Natural Logarithm

Convert: e² ≈ 7.389

Logarithmic form: ln(7.389) ≈ 2

Note: ln represents log with base e

Example 4: Common Logarithm

Convert: log(100) = 2

Exponential form: 10² = 100

Note: log without a base means log₁₀

Method 1: Exponential to Logarithmic

Example: Convert 7² = 49
1 Identify Components: a = 7, x = 2, b = 49
2 Recall the Pattern: ax = b becomes loga(b) = x
3 Apply the Pattern: log₇(49) = 2
4 Answer: log₇(49) = 2

Method 2: Logarithmic to Exponential

Example: Convert log₂(64) = 6
1 Identify Components: a = 2, x = 6, b = 64
2 Recall the Pattern: loga(b) = x becomes ax = b
3 Apply the Pattern: 2⁶ = 64
4 Verify: 2 × 2 × 2 × 2 × 2 × 2 = 64 ✓

Method 3: Natural Logarithm

Example: Convert ln(20.09) ≈ 3
1 Identify the Base: ln means base e (e ≈ 2.71828)
2 Identify Components: a = e, x = 3, b ≈ 20.09
3 Apply Conversion: e³ ≈ 20.09
4 Answer: e³ ≈ 20.09

Method 4: Common Logarithm

Example: Convert log(1000) = 3
1 Identify the Base: log without a base means base 10
2 Identify Components: a = 10, x = 3, b = 1000
3 Apply Conversion: 10³ = 1000
4 Verify: 10 × 10 × 10 = 1000 ✓

Practice Problems

Problem 1: Convert to logarithmic form

Easy

Convert to logarithmic form: 7² = 49

Step 1: Identify a = 7, x = 2, b = 49
Step 2: Apply ax = b → loga(b) = x
Answer: log₇(49) = 2

Problem 2: Convert to exponential form

Easy

Convert to exponential form: log₂(64) = 6

Step 1: Identify a = 2, x = 6, b = 64
Step 2: Apply loga(b) = x → ax = b
Answer: 2⁶ = 64

Problem 3: Natural logarithm

Easy

Convert to exponential form: ln(20.09) ≈ 3

Step 1: ln means base e
Step 2: Identify a = e, x = 3, b ≈ 20.09
Step 3: Apply ln(b) = x → ex = b
Answer: e³ ≈ 20.09

Problem 4: Mixed conversions

Medium

Convert both ways: If 4x = 256, write in logarithmic form

Step 1: Find x: 4 × 4 × 4 × 4 = 256, so x = 4
Step 2: The equation is 4⁴ = 256
Step 3: Convert using ax = b → loga(b) = x
Answer: log₄(256) = 4

Problem 5: Complex conversion

Medium

Convert to logarithmic form: 6³ = 216

Step 1: Identify a = 6, x = 3, b = 216
Step 2: Verify: 6 × 6 × 6 = 216 ✓
Step 3: Apply ax = b → loga(b) = x
Answer: log₆(216) = 3
