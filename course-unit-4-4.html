Unit 4.4: Solutions of Indicial Equations

Solve exponential equations using indices and logarithms

🔢 3 Kaedah Untuk Indicial Equations

Kaedah 1: Comparison of Base

Bandingkan base bila boleh express sama. Guna apabila kedua-dua sides boleh ditulis dengan base yang sama.

Langkah: Express kedua-dua sides dengan base sama, bandingkan powers, kemudian solve untuk x.

Contoh: 2x = 8 = 2³, maka x = 3.

Kaedah 2: Using Laws of Indices

Guna laws untuk simplify dahulu apabila ada products atau quotients.

Langkah: Apply laws of indices, express dengan base sama, kemudian solve untuk x.

Contoh: 2x × 2³ = 32; 2x+3 = 2⁵; x + 3 = 5; maka x = 2.

Kaedah 3: Logarithmic Form

Convert apabila tidak boleh express kedua-dua sides dengan base yang sama.

Langkah: Isolate ax = b, convert kepada x = loga b, kemudian calculate nilai x.

Contoh: 3x = 20; x = log₃ 20 = log 20 / log 3 ≈ 2.73.

Nota Form 5: Substitution

Kadang-kadang, gunakan substitution (contohnya, let y = ax) untuk menukar soalan indices kepada bentuk kuadratik, ay² + by + c = 0.

Contoh bentuk: 22x - 5(2x) + 4 = 0.

🤔 Decision Guide: Pilih Method

Boleh express dengan base yang sama? Ya → Kaedah 1: Comparison.

Ada products atau quotients? Ya → Kaedah 2: Laws.

Boleh jadi kuadratik (contohnya a2x)? Ya → Substitution (let y = ax).

Jika tidak, gunakan Kaedah 3: Logarithmic Form.

✏️ Try It: Indicial Equations

Cuba selesaikan setiap soalan, kemudian tunjukkan penyelesaian langkah demi langkah.

Example 1: Comparison Method (Mudah)

Solve: 2x = 16

16 = 2⁴
2x = 2⁴
x = 4

Example 2: Laws Method (Mudah)

Solve: 3x × 3² = 81

3x+2 = 81 = 3⁴
x + 2 = 4
x = 2

Example 3: Logarithmic Form (Sederhana)

Solve to 2 decimal places: 2x = 10

10 is not a perfect power of 2, so use logarithmic form.
x = log2 10 = log 10 / log 2 ≈ 3.32

Practice: Quadratic Form

Solve: 4x - 5(2x) + 4 = 0

Let y = 2x, so 4x = y².
y² - 5y + 4 = 0
(y - 1)(y - 4) = 0, so y = 1 or 4.
2x = 1 gives x = 0; 2x = 4 gives x = 2.
x = 0 or x = 2
