Unit 4.4: Solutions of Indicial Equations

Solve exponential equations using indices and logarithms

What is an Indicial Equation?

An indicial equation (or exponential equation) is one where the variable appears in an exponent.

Examples: 2x = 8 or 32x = 27 or 5x = 100

Method 1: Same Base

Strategy

If both sides have the same base, equate the exponents:

If ax = ay, then x = y

Example 1

Solve: 2x = 8

Step 1: Rewrite 8 as a power of 2
8 = 2³

Step 2: Rewrite the equation
2x = 2³

Step 3: Equate exponents
x = 3

Example 2

Solve: 9x = 27

9 = 3², 27 = 3³
(3²)x = 3³
32x = 3³
2x = 3, so x = 1.5

Method 2: Using Logarithms

Strategy

When bases cannot be made the same, take logarithms of both sides:

ax = b ⟹ x × log(a) = log(b) ⟹ x = log(b)/log(a)

Example 3

Solve: 5x = 100

Step 1: Take logarithms of both sides
log(5x) = log(100)

Step 2: Apply power rule
x × log(5) = log(100)

Step 3: Solve for x
x = log(100) / log(5) = 2 / 0.699 ≈ 2.86

Example 4

Solve: 23x+1 = 16

Rewrite 16 as 2⁴:
23x+1 = 2⁴

Equate exponents:
3x + 1 = 4

Solve:
3x = 3
x = 1

Method 3: Quadratic Indicial Equations

Some equations become quadratic when we substitute.

Example 5

Solve: 4x - 5(2x) + 4 = 0

Step 1: Note that 4x = (2²)x = (2x)²
Let y = 2x

Step 2: Rewrite the equation
y² - 5y + 4 = 0

Step 3: Factor
(y - 4)(y - 1) = 0
y = 4 or y = 1

Step 4: Substitute back
If 2x = 4: x = 2
If 2x = 1: x = 0

Solutions: x = 0 or x = 2

Real-World Applications

Application 1: Compound Interest

Problem: An investment grows according to the formula A = P(1.05)t, where A is the amount, P is principal, and t is time in years. If you invest RM1000 and want it to grow to RM2000, how many years will it take?

Solution:

2000 = 1000(1.05)t

2 = (1.05)t

Take logarithms: log(2) = t × log(1.05)

t = log(2) / log(1.05) ≈ 14.2 years

Application 2: Radioactive Decay

Problem: A radioactive substance follows N = N₀(0.5)t/T, where T is half-life. Carbon-14 has T = 5730 years. After 11,460 years, what fraction remains?

Solution:

N = N₀(0.5)11460/5730

N = N₀(0.5)2

N = N₀ × 0.25 = 1/4 of the original

Application 3: Bacterial Growth

Problem: A bacterial colony doubles every 3 hours. If we start with 100 bacteria and want 6400 bacteria, how long will it take?

Solution:

6400 = 100 × 2t/3

64 = 2t/3

26 = 2t/3

6 = t/3

t = 18 hours

Practice Problems

Problem 1: Same base method

Easy

Solve: 3x = 81

3x = 81 = 3⁴ Therefore x = 4

Problem 2: Logarithm method

Easy

Solve: 2x = 50

log(2x) = log(50) x × log(2) = log(50) x = log(50) / log(2) ≈ 5.64

Problem 3: Linear exponent

Medium

Solve: 22x+1 = 32

22x+1 = 32 = 2⁵ 2x + 1 = 5 2x = 4 x = 2

Problem 4: Quadratic form

Hard

Solve: 9x - 10(3x) + 9 = 0

Let y = 3x, so 9x = y² y² - 10y + 9 = 0 (y - 1)(y - 9) = 0 y = 1 or y = 9 3x = 1 ⟹ x = 0 3x = 9 = 3² ⟹ x = 2
