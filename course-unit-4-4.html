Unit 4.4: Solutions of Indicial Equations

Comprehensive Guide - 3 Methods & Practice Problems

📚 What is an Indicial Equation?

An indicial equation (exponential equation) is one where the variable appears in an exponent.

Examples: 2x = 8 | 32x = 27 | 5x = 100

🔢 3 Methods to Solve Indicial Equations

Method 1: Comparison of Base

When to use: When both sides can be expressed with the SAME BASE

Strategy: If ax = ay, then x = y

Example:
2x = 8 = 2³
∴ x = 3

Method 2: Using Laws of Indices

When to use: When there are products/quotients needing SIMPLIFICATION

Strategy: Apply laws to get same base, then compare

Example:
3x × 3² = 81 = 3⁴
3x+2 = 3⁴
x + 2 = 4 ∴ x = 2

Method 3: Logarithmic Form

When to use: When you CAN'T express with same base

Strategy: ax = b ⟹ x = logab

Example:
5x = 100
x = log₅(100) = log(100)/log(5)
x ≈ 2.86

🤔 Decision Guide: Which Method to Use?

❓ Can you express both sides with the SAME BASE?

✓ YES → Use Method 1: Comparison

✗ NO → Continue below

↓
❓ Are there products/quotients of powers?

✓ YES → Use Method 2: Laws of Indices

✗ NO → Continue below

↓
❓ Is it a quadratic form (e.g., a2x)?

✓ YES → Use Substitution (let y = ax)

✗ NO → Use Method 3: Logarithmic Form

Method 1: Comparison - Detailed Examples

Example 1A: Simple Comparison

Solve: 2x = 8

Step 1: Express 8 as a power of 2

8 = 2 × 2 × 2 = 2³

Step 2: Rewrite equation: 2x = 2³

Step 3: Compare exponents: x = 3

Example 1B: Different Bases

Solve: 9x = 27

Step 1: Express both with base 3:

9 = 3², 27 = 3³

Step 2: (3²)x = 3³

Step 3: 32x = 3³

Step 4: 2x = 3, so x = 1.5

Method 2: Laws of Indices - Detailed Examples

Example 2A: Product Rule

Solve: 2x × 2³ = 32

Step 1: Apply product rule: am × an = am+n

2x+3 = 32

Step 2: Express 32 as power of 2: 32 = 2⁵

2x+3 = 2⁵

Step 3: x + 3 = 5, so x = 2

Example 2B: Complex Expression

Solve: 3x ÷ 3² = 27

Step 1: Apply quotient rule: am ÷ an = am-n

3x-2 = 27 = 3³

Step 2: x - 2 = 3

Step 3: x = 5

Method 3: Logarithmic Form - Detailed Examples

Example 3A: Basic Logarithmic

Solve: 5x = 100

Step 1: Can we express 100 as power of 5? NO - cannot easily

Step 2: Use logarithmic form: x = log₅(100)

Step 3: Convert to common logarithm: x = log(100)/log(5)

Step 4: Calculate: x = 2/0.699 ≈ 2.86

Example 3B: Linear Exponent

Solve: 23x+1 = 16

Step 1: Express 16 as power of 2: 16 = 2⁴

23x+1 = 2⁴

Step 2: Equate exponents: 3x + 1 = 4

Step 3: 3x = 3, so x = 1

Quadratic Indicial Equations (Form 5)

Example 4: Substitution Method

Solve: 4x - 5(2x) + 4 = 0

Step 1: Recognize: 4x = (2²)x = (2x)²

Let y = 2x

Step 2: Equation becomes: y² - 5y + 4 = 0

Step 3: Factor: (y - 4)(y - 1) = 0

y = 4 or y = 1

Step 4: Substitute back:

If 2x = 4 = 2²: x = 2

If 2x = 1 = 2⁰: x = 0

Solutions: x = 0 or x = 2

Real-World Applications

Application 1: Compound Interest

Problem: An investment grows according to A = P(1.05)t. If you invest RM1000 and want it to grow to RM2000, how many years will it take?

Solution: 2000 = 1000(1.05)t

2 = (1.05)t

t = log(2) / log(1.05) ≈ 14.2 years

Application 2: Radioactive Decay

Problem: N = N₀(0.5)t/T where T = 5730 years. After 11,460 years, what fraction remains?

Solution: N = N₀(0.5)11460/5730 = N₀(0.5)² = N₀ × 0.25 = 1/4 of original

Application 3: Bacterial Growth

Problem: Bacteria double every 3 hours. Starting with 100, when will we have 6400?

Solution: 6400 = 100 × 2t/3

64 = 2t/3 = 2⁶

t/3 = 6, so t = 18 hours

⚠️ Common Mistakes & 💡 Tips

⚠️ Common Mistakes

Forgetting to apply laws consistently: If you have am × an, you must add the exponents, not multiply them.
Mixing up bases: 2x = 8 is NOT the same as 2x = 9. Make sure you express both sides with truly the same base.
Ignoring quadratic solutions: When using substitution, remember you might get TWO values for x, not just one.
Calculator errors: When using logarithms, use log(a)/log(b), NOT log(a/b).
Not checking negative results: Some methods might give negative exponents - these are valid!

💡 Quick Tips

Try comparison first: It's the simplest if it works!
Memorize key powers: Know 2⁰, 2¹, 2², 2³, 2⁴, 2⁵, 2⁶, 2⁷, 2⁸, 2¹⁰ and 3⁰, 3¹, 3², 3³, 3⁴, 3⁵
Look for patterns: If you see a2x or a3x with a corresponding ax term, think SUBSTITUTION.
Verify your answer: Substitute back into the original equation to check!
Use logarithm as last resort: It's powerful but might give non-integer answers.

📝 Practice Problems

Problem 1: Comparison Method

Easy

Solve: 3x = 81

3x = 81 = 3⁴
Therefore x = 4

Problem 2: Logarithm Method

Easy

Solve: 2x = 50

log(2x) = log(50)
x × log(2) = log(50)
x = log(50) / log(2) ≈ 5.64

Problem 3: Laws of Indices

Medium

Solve: 22x+1 = 32

22x+1 = 32 = 2⁵
2x + 1 = 5
2x = 4
x = 2

Problem 4: Quadratic Form (Form 5)

Hard

Solve: 9x - 10(3x) + 9 = 0

Let y = 3x, so 9x = y²
y² - 10y + 9 = 0
(y - 1)(y - 9) = 0
y = 1 or y = 9
3x = 1 ⟹ x = 0
3x = 9 = 3² ⟹ x = 2
Solutions: x = 0, 2
