Problem 9: Complex Logarithmic Equation

Solve: log₂(x) + log₂(x-2) = 3

Using product rule: log₂[x(x-2)] = 3 x(x-2) = 2³ = 8 x² - 2x - 8 = 0 (x-4)(x+2) = 0 x = 4 or x = -2 Since x must be positive: x = 4
