Unit 4.5: Solutions of Logarithmic Equations

Comprehensive Guide - 3 Methods & Real-World Applications

📊 What is a Logarithmic Equation?

A logarithmic equation contains logarithms of variables or expressions.

Examples: log(x) = 2 | log₂(x) = 5 | ln(x+1) = 3 | log(x) + log(3) = 1

📋 3 Methods to Solve Logarithmic Equations

Method 1: Comparison

When to use: Single log on each side with SAME BASE

Strategy: If loga(x) = loga(y), then x = y

Example:
log₂ x = log₂ 8
∴ x = 8

Method 2: Laws of Logarithms

When to use: Multiple logs that need combining

Strategy: Use laws to combine, then solve

Example:
log(x) + log(3) = log(15)
log(3x) = log(15)
3x = 15 ∴ x = 5

Method 3: Index Form

When to use: Single log equals constant

Strategy: Convert: loga(b) = x ⟹ ax = b

Example:
log₂(x) = 5
2⁵ = x
∴ x = 32

🤔 Decision Guide: Which Method to Use?

❓ Single log on each side with the SAME BASE?

✓ YES → Use Method 1: Comparison

✗ NO → Continue below

↓
❓ Multiple logs that can be combined?

✓ YES → Use Method 2: Laws of Logarithms

✗ NO → Continue below

↓
❓ Different bases OR quadratic form?

✓ YES (Form 5) → Use Change Base or Substitution

✗ NO → Use Method 3: Index Form

Method 1: Comparison - Detailed Examples

Example 1A: Basic Comparison

Solve: log₂ x = log₂ 8

Step 1: Check base - same base (2) on both sides ✓

Step 2: Compare arguments: x = 8

Verification: log₂(8) = log₂(2³) = 3 ✓

Example 1B: With Constants

Solve: log₃ x = log₃ 9

Step 1: Bases are same (3) ✓

Step 2: x = 9

Verification: log₃(9) = log₃(3²) = 2 ✓

Method 2: Laws of Logarithms - Detailed Examples

Example 2A: Product Rule

Solve: log(x) + log(3) = log(15)

Step 1: Apply product rule: log(A) + log(B) = log(AB)

log(3x) = log(15)

Step 2: Compare: 3x = 15

Step 3: x = 5

Verification: log(5) + log(3) = log(15) ✓

Example 2B: Quotient Rule

Solve: log(x) - log(2) = 1

Step 1: Apply quotient rule: log(A) - log(B) = log(A/B)

log(x/2) = 1

Step 2: Convert to exponential: 10¹ = x/2

Step 3: 10 = x/2, so x = 20

Verification: log(20) - log(2) = log(20/2) = log(10) = 1 ✓

Method 3: Index Form - Detailed Examples

Example 3A: Simple Index Form

Solve: log₂(x) = 5

Step 1: Convert to exponential form: loga(b) = x ⟹ ax = b

2⁵ = x

Step 2: Calculate: x = 32

Verification: log₂(32) = log₂(2⁵) = 5 ✓

Example 3B: With Expression

Solve: log₅(x - 2) = 2

Step 1: Convert to exponential: 5² = x - 2

Step 2: Calculate: 25 = x - 2

Step 3: x = 27

Verification: log₅(27 - 2) = log₅(25) = log₅(5²) = 2 ✓

Example 3C: Natural Logarithm

Solve: ln(x) = 2

Step 1: Convert: e² = x

Step 2: Calculate: x = e² ≈ 7.389

Verification: ln(7.389) ≈ 2 ✓

Complex Logarithmic Equations

Example 4: Product Rule with Multiple Terms

Solve: log₂(x) + log₂(x-2) = 3

Step 1: Use product rule: log₂[x(x-2)] = 3

Step 2: Convert to exponential: x(x-2) = 2³ = 8

Step 3: Expand: x² - 2x = 8

Step 4: Rearrange: x² - 2x - 8 = 0

Step 5: Factor: (x - 4)(x + 2) = 0

Step 6: x = 4 or x = -2

Step 7: Check validity: x = -2 is INVALID (log of negative)
Solution: x = 4

Example 5: Using Power Rule

Solve: log(x²) = 4

Step 1: Apply power rule: 2log(x) = 4

Step 2: Simplify: log(x) = 2

Step 3: Convert: 10² = x

Step 4: x = 100

Note: When solving log(x²), remember x² is always positive,
so both positive and negative x values need checking!

⚠️ Important: Domain Restrictions

🚨 You can ONLY take logarithm of POSITIVE numbers!

  • Arguments must be > 0: In log(x), we need x > 0
  • Check your solutions: Always substitute back to verify
  • Reject invalid solutions: If log(negative) appears, reject that solution
  • Domain of log(f(x)): We need f(x) > 0

Domain Restriction Example

Solve: log(x) + log(x-1) = 1

Domain: We need x > 0 AND x - 1 > 0
Therefore: x > 1

Solution: log[x(x-1)] = 1

x(x-1) = 10
x² - x - 10 = 0

Using quadratic formula: x = (1 ± √41)/2

x ≈ 3.70 or x ≈ -2.70

Check domain:

x ≈ 3.70: Valid (> 1) ✓
x ≈ -2.70: Invalid (not > 1) ✗

Final Answer: x ≈ 3.70

Real-World Applications

Application 1: Sound Intensity (Decibels)

Formula: dB = 10 log₁₀(I/I₀) where I₀ = 10⁻¹² W/m²

Problem: If a sound is 80 dB, what is its intensity?

Solution:
80 = 10 log₁₀(I/10⁻¹²)
8 = log₁₀(I/10⁻¹²)
10⁸ = I/10⁻¹²
I = 10⁸ × 10⁻¹² = 10⁻⁴ W/m²

Application 2: Richter Scale (Earthquakes)

Formula: R = log₁₀(A) where A is amplitude

Problem: If an earthquake has magnitude 7, what is its amplitude?

Solution:
7 = log₁₀(A)
A = 10⁷ = 10,000,000 micrometers

Application 3: pH Level (Chemistry)

Formula: pH = -log₁₀[H⁺]

Problem: If a solution has pH = 3, what is [H⁺]?

Solution:
3 = -log₁₀[H⁺]
-3 = log₁₀[H⁺]
[H⁺] = 10⁻³ = 0.001 mol/L

Application 4: Carbon Dating

Formula: t = (1/λ) ln(N/N₀)

Problem: If an artifact has 25% of original C-14 (λ ≈ 0.000121/year), how old?

Solution:
t = (1/0.000121) ln(0.25)
t = 8264.5 × (-1.386)
t ≈ 11,460 years

⚠️ Common Mistakes & 💡 Tips

⚠️ Common Mistakes

Forgetting domain: log(x) only exists when x > 0. Always check!
Wrong base conversion: log(A + B) ≠ log(A) + log(B). Be careful!
Ignoring domain when solving: You might get 2 solutions from algebra, but only 1 is valid after domain check.
Not using correct base: Check if log means log₁₀ or ln or some other base!
Forgetting to solve after substitution: If you use let y = log(x), solve for y first, THEN for x.

💡 Quick Tips

Try comparison first: Fastest if both sides are single logs with same base.
Know key logs: log₁₀(10) = 1, log₁₀(100) = 2, log₁₀(1) = 0, ln(e) = 1
Convert to exponential: This often makes the algebra simpler.
Always verify answers: Substitute back - especially checking domain!
Quadratic in disguise: Look for patterns like (log x)² or logx pattern.

📋 Reference: Laws of Logarithms

Essential Laws

Law Formula Example
Product log(MN) = log(M) + log(N) log(30) = log(3) + log(10)
Quotient log(M/N) = log(M) - log(N) log(5) = log(50) - log(10)
Power log(Mp) = p log(M) log(x³) = 3log(x)
Change of Base loga(b) = log(b)/log(a) log₂(8) = log(8)/log(2) = 3
Reciprocal loga(b) = 1/logb(a) log₂(8) = 1/log₈(2)
Special Cases loga(a) = 1, loga(1) = 0 log₁₀(10) = 1, log₅(1) = 0

📊 Quick Reference: Methods Summary

Method When to Use Example
1. Comparison Single log, same base log₂ x = log₂ 8 → x = 8
2. Laws Multiple logs, combine log x + log 2 = log 10 → x = 5
3. Index Form Single log = constant log₂ x = 3 → x = 8
4. Change Base (F5) Different bases log₂ x + log₄ x = 6 → x = 16
5. Substitution (F5) Quadratic form log₃ x + 4 logx 3 = 4 → x = 3, 81

📝 Practice Problems

Problem 1: Comparison Method

Easy

Solve: log₃(x) = 2

Convert to exponential: 3² = x
x = 9

Problem 2: Natural Logarithm

Easy

Solve: ln(x) = 1

e¹ = x
x = e ≈ 2.718

Problem 3: Laws of Logarithms

Medium

Solve: log(x) + log(5) = 1

log(5x) = 1
5x = 10¹ = 10
x = 2

Problem 4: Product Rule with Domain Check

Hard

Solve: log₂(x) + log₂(x+1) = 1

log₂[x(x+1)] = 1
x(x+1) = 2¹ = 2
x² + x - 2 = 0
(x + 2)(x - 1) = 0
x = -2 or x = 1
Domain check: x > 0, so x = 1 (reject x = -2)
Solution: x = 1
