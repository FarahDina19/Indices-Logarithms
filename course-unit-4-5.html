Unit 4.5: Solutions of Logarithmic Equations

Solve equations involving logarithms using properties and exponential form

What is a Logarithmic Equation?

A logarithmic equation contains logarithms of variables.

Examples: log(x) = 2 or log₂(x) = 5 or ln(x+1) = 3

Method 1: Convert to Exponential Form

Strategy

Use the definition: If log_a(x) = y, then ay = x

Example 1

Solve: log₂(x) = 5

Step 1: Convert to exponential form
2⁵ = x

Step 2: Calculate
x = 32

Example 2

Solve: log(x) = 3

Convert to exponential: 10³ = x
x = 1000

Example 3

Solve: ln(x) = 2

Convert to exponential: e² = x
x ≈ 7.389

Method 2: Using Logarithm Laws

Strategy

Apply logarithm laws to simplify, then convert to exponential form.

Example 4

Solve: log(2x) = 1

Step 1: Convert to exponential
10¹ = 2x

Step 2: Solve for x
10 = 2x
x = 5

Example 5

Solve: log(x²) = 4

Step 1: Convert to exponential
10⁴ = x²

Step 2: Solve for x
10000 = x²
x = ±100

Note: Must check that solutions are valid for the original equation

Method 3: Complex Logarithmic Equations

Example 6

Solve: log₂(x) + log₂(x-2) = 3

Step 1: Use product rule
log₂[x(x-2)] = 3

Step 2: Convert to exponential
x(x-2) = 2³ = 8

Step 3: Expand and rearrange
x² - 2x = 8
x² - 2x - 8 = 0

Step 4: Factor
(x - 4)(x + 2) = 0
x = 4 or x = -2

Step 5: Check validity
x = -2 is invalid (log of negative)
x = 4

Example 7

Solve: log(x) - log(x-1) = 1

Step 1: Use quotient rule
log[x/(x-1)] = 1

Step 2: Convert to exponential
x/(x-1) = 10¹ = 10

Step 3: Solve for x
x = 10(x-1)
x = 10x - 10
-9x = -10
x = 10/9 ≈ 1.11

Real-World Applications

Application 1: Sound Intensity (Decibels)

Problem: The decibel level is given by dB = 10 log₁₀(I/I₀), where I is intensity and I₀ = 10⁻¹² (reference). If a sound is 80 dB, what is its intensity?

Solution:

80 = 10 log₁₀(I/10⁻¹²)

8 = log₁₀(I/10⁻¹²)

10⁸ = I/10⁻¹²

I = 10⁸ × 10⁻¹² = 10⁻⁴ W/m²

Application 2: Richter Scale (Earthquakes)

Problem: The Richter magnitude is R = log₁₀(A), where A is amplitude. If an earthquake has magnitude 7, what is its amplitude?

Solution:

7 = log₁₀(A)

A = 10⁷ = 10,000,000 micrometers

Application 3: pH Level (Chemistry)

Problem: pH = -log₁₀[H⁺]. If a solution has pH = 3, what is the hydrogen ion concentration [H⁺]?

Solution:

3 = -log₁₀[H⁺]

-3 = log₁₀[H⁺]

[H⁺] = 10⁻³ = 0.001 mol/L

Application 4: Carbon Dating

Problem: Using t = (1/λ) ln(N/N₀), if an artifact has 25% of original C-14 (λ ≈ 0.000121/year), how old is it?

Solution:

t = (1/0.000121) ln(0.25)

t = 8264.5 × (-1.386)

t ≈ 11,460 years

Important: Domain Restrictions

Remember: You can only take the logarithm of positive numbers!

Always check:

  • Arguments must be positive (> 0)
  • Reject solutions that violate the domain
  • Verify solutions in the original equation

Practice Problems

Easy

Problem 2: Natural logarithm

Easy

Solve: ln(x) = 1

e¹ = x x = e ≈ 2.718

Problem 3: Logarithm with arithmetic

Medium

Solve: log(3x) = 2

10² = 3x 100 = 3x x = 100/3 ≈ 33.33

Problem 4: Using logarithm laws

Medium

Solve: log(x) + log(5) = 1

log(5x) = 1 5x = 10¹ = 10 x = 2

Problem 5: Product rule

Hard

Solve: log₂(x) + log₂(x+1) = 1

log₂[x(x+1)] = 1 x(x+1) = 2¹ = 2 x² + x - 2 = 0 (x + 2)(x - 1) = 0 x = -2 or x = 1 Valid: x = 1 (reject x = -2 as it's negative)
