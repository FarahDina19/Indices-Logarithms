Unit 4.5: Solutions of Logarithmic Equations

Solve equations involving logarithms using properties and exponential form

📊 3 Kaedah Untuk Logarithmic Equations

Kaedah 1: Comparison of Base

Bandingkan arguments apabila base sama. Gunakan untuk satu logarithm pada setiap side dengan base yang sama.

Langkah: Check base sama, bandingkan arguments, kemudian solve untuk x.

Contoh: log₂ x = log₂ 8, maka x = 8.

Kaedah 2: Laws of Logarithms

Combine atau expand logarithms apabila terdapat beberapa logarithms.

Langkah: Apply laws untuk combine, simplify kepada single log, kemudian compare atau solve.

Contoh: log x + log 3 = log 15; log(3x) = log 15; 3x = 15; maka x = 5.

Kaedah 3: Change to Index Form

Convert untuk menghapuskan log apabila perlu atau kaedah lain tidak sesuai.

Langkah: Simplify jika perlu, convert loga b = x kepada ax = b, kemudian solve indicial equation.

Contoh: log₂ (x + 1) = 3; 2³ = x + 1; maka x = 7.

Nota Form 5

Untuk soalan logarithms yang lebih kompleks, tukar asas menggunakan loga b = logc b / logc a. Jika terdapat corak berulang seperti (log x)², gunakan substitution (let y = log x) untuk menukar kepada bentuk kuadratik.

Contoh (Change Base): log₂ x + log₄ x = 6.

Contoh (Substitution): log₃ x + 4 logx 3 = 4.

🤔 Decision Guide: Pilih Method

Single log each side, base sama? Ya → Kaedah 1: Comparison.

Multiple logs boleh combine? Ya → Kaedah 2: Laws.

Ada base berbeza atau bentuk kuadratik? Ya → Change Base atau Substitution (Form 5).

Jika tidak, gunakan Kaedah 3: Index Form.

⚠️ Domain Restrictions

Logarithm argument mesti lebih besar daripada 0. Always check arguments, reject solutions that violate the domain, and verify solutions in the original equation.

✏️ Try It: Logarithmic Equations

Cuba selesaikan setiap soalan, kemudian tunjukkan penyelesaian langkah demi langkah.

Example 1: Comparison Method (Mudah)

Solve: log₃ x = log₃ 9

Base sama, jadi arguments sama.
x = 9

Example 2: Laws Method (Mudah)

Solve: log₂ x + log₂ 4 = log₂ 12

log₂ (x × 4) = log₂ 12
4x = 12
x = 3

Example 3: Index Form (Sederhana)

Solve: log₅ (x - 2) = 2

5² = x - 2
25 = x - 2
x = 27
