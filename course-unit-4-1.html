What Are Indices?

An index (or exponent) tells us how many times a number (the base) is multiplied by itself.

General form: an where a is the base and n is the index

34
3 Base
4 Index/Exponent

3 × 3 × 3 × 3 = 81

Key Terminology

Base
The number being multiplied repeatedly
Index/Exponent
The power showing how many times to multiply
Power
The entire expression (e.g., 3⁴)
Square
A number raised to the power 2
Cube
A number raised to the power 3
Coefficient
The number multiplied by the power

The 8 Laws of Indices

Law 1: Multiplication with Same Base
am × an = am+n

When multiplying powers with the same base, add the exponents

Law 2: Division with Same Base
am ÷ an = am-n

When dividing powers with the same base, subtract the exponents

Law 3: Power of a Power
(am)n = amn

When raising a power to another power, multiply the exponents

Law 4: Power of a Product
(ab)n = anbn

Apply the power to each factor in the product

Law 5: Power of a Quotient
(a/b)n = an/bn

Apply the power to both numerator and denominator

Law 6: Zero Index
a0 = 1 (where a ≠ 0)

Any non-zero number to the power 0 equals 1

Law 7: Negative Index
a-n = 1/an

A negative exponent means "take the reciprocal"

Law 8: Fractional Index
am/n = n√(am)

Fractional exponents represent roots

Worked Examples

Example 1: Multiplication Rule (Law 1)

Simplify: x³ × x⁵

Solution:
Using Law 1: am × an = am+n
x³ × x⁵ = x3+5 = x⁸

Example 2: Power of a Power (Law 3)

Simplify: (y²)⁴

Solution:
Using Law 3: (am)n = amn
(y²)⁴ = y2×4 = y⁸

Example 3: Negative Exponent (Law 7)

Simplify: 2⁻³

Solution:
Using Law 7: a-n = 1/an
2⁻³ = 1/2³ = 1/8 = 0.125

Example 4: Fractional Index (Law 8)

Simplify: 9½

Solution:
Using Law 8: am/n = n√(am)
9½ = √9 = 3

Practice Problems

Problem 1: Simplify using laws of indices

Easy

Simplify: a² × a³ × a

a² × a³ × a = a^(2+3+1) = a⁶

Problem 2: Evaluate negative exponents

Easy

Evaluate: 5⁻²

5⁻² = 1/5² = 1/25 = 0.04

Problem 3: Power of a power

Medium

Simplify: (x²)³ × (x²)²

(x²)³ × (x²)² = x⁶ × x⁴ = x^(6+4) = x¹⁰

Problem 4: Fractional exponents

Medium

Evaluate: 27^(1/3)

27^(1/3) = ³√27 = 3

Problem 5: Complex simplification

Hard

Simplify: (2a³b⁻²)² × (3a⁻¹b)²

(2a³b⁻²)² × (3a⁻¹b)² = 4a⁶b⁻⁴ × 9a⁻²b² = 36a⁴b⁻² = 36a⁴/b²
