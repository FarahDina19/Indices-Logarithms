🔢 3 Kaedah Untuk Indicial Equations

KAEDAH 1

Comparison of Base

Bandingkan base bila boleh express sama.

📌 Bila nak guna: Bila kedua-dua sides boleh ditulis dengan BASE YANG SAMA
Express kedua-dua sides dengan base sama
Bandingkan powers
Solve untuk x
Contoh: 2x = 8
2x = 2³
∴ x = 3
KAEDAH 2

Using Laws of Indices

Guna laws untuk simplify dulu.

📌 Bila nak guna: Bila ada products/quotients perlu SIMPLIFY
Apply laws of indices
Express same base
Solve untuk x
Contoh: 2x × 2³ = 32
2x+3 = 2⁵
x + 3 = 5
∴ x = 2
KAEDAH 3

Logarithmic Form

Convert bila tak boleh same base.

📌 Bila nak guna: Bila TAK BOLEH express same base
Isolate ax = b
Convert: x = loga b
Calculate nilai x
Contoh: 3x = 20
x = log₃ 20
x = log 20 / log 3
x ≈ 2.73

💡 Nota Form 5

Kadang-kadang, anda perlu guna substitution (e.g., let y = ax) untuk menukar soalan indices kepada bentuk kuadratik (ay² + by + c = 0) sebelum menyelesaikannya.

Contoh: 22x - 5(2x) + 4 = 0

📊 3 Kaedah Untuk Logarithmic Equations

KAEDAH 1

Comparison of Base

Bandingkan arguments bila base sama.

📌 Bila nak guna: Single log each side, BASE SAMA
Check base sama
Bandingkan arguments
Solve untuk x
Contoh: log₂ x = log₂ 8
∴ x = 8
KAEDAH 2

Laws of Logarithms

Combine atau expand logs.

📌 Bila nak guna: Multiple logs perlu COMBINE
Apply laws untuk combine
Simplify to single log
Compare atau solve
Contoh: log x + log 3 = log 15
log(3x) = log 15
3x = 15
∴ x = 5
KAEDAH 3

Change to Index Form

Convert to eliminate log.

📌 Bila nak guna: Perlu CONVERT atau method lain tak jalan
Simplify if needed
Convert: loga b = x → ax = b
Solve indicial equation
Contoh: log₂ (x + 1) = 3
2³ = x + 1
8 = x + 1
∴ x = 7

💡 Nota Form 5

Untuk soalan Logarithms yang lebih kompleks, anda mungkin perlu:

  • Tukar Asas (Change Base): Gunakan formula loga b = logc b / logc a untuk samakan asas.
  • Substitution: Jika nampak corak berulang (e.g., (log x)²), guna substitution (let y = log x) untuk tukar ke bentuk kuadratik.

Contoh (Change Base): log₂ x + log₄ x = 6

Contoh (Substitution): log₃ x + 4 logx 3 = 4

⚠️ Common Mistakes & 💡 Tips

⚠️ Kesilapan Biasa

Logarithm argument: log(x) hanya wujud kalau x > 0! Check jawapan akhir.
Kuadratik: Jangan lupa selesaikan untuk x selepas dapat nilai y (e.g., if y=ax). Mungkin ada 2 jawapan.
Base confusion: Pastikan base SAMA sebelum compare/guna laws. Guna Change Base jika perlu.
Laws application: log(A + B) ≠ log A + log B. Hati-hati bila combine/expand.

💡 Tips Mudah Ingat

Try comparison first: Paling simple kalau boleh.
Look for Quadratics: Kenal pasti bentuk a2x atau (log x)². Guna substitution.
Change Base: Jika ada log berbeza base, tukar ke base yang sama (biasanya base 10 atau base terkecil).
Verify answer: Substitute balik jawapan ke soalan asal, especially for logs (pastikan argument > 0).

📐 Key Formulas

Laws of Indices

am × an = am+n
am ÷ an = am-n
(am)n = amn
a0 = 1
a-n = 1/an
am/n = ⁿ√(am)

Laws of Logs

loga(MN) = loga M + loga N
loga(M/N) = loga M - loga N
loga(Mp) = p loga M

Conversions & Base

ax = N ⟺ loga N = x
loga b = logc b / logc a
loga b = 1 / logb a
loga a = 1, loga 1 = 0
